# Retail Sales Analysis Using Microsoft Excel

## About This Project

This is my beginner-level Data Analytics project. I created this project to practise analyzing supermarket sales data using Microsoft Excel.

## Dataset

- Contains 20 sample sales transactions.
- Covers 2 January to 11 January 2026.
- Includes product names, categories, quantities, unit prices, and total sales.
- Created for learning and practice purposes.

## Tools Used

- Microsoft Excel

## Excel Skills Used

- Data organization and formatting.
- SUM formula.
- AVERAGE formula.
- MIN formula.
- MAX formula.
- COUNT formula.

## Project Goals

- Understand and organize sales data.
- Calculate total sales.
- Find average sales.
- Identify minimum and maximum sales.
- Practise basic Excel formulas.
